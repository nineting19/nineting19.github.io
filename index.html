拾玖搜证台是什么？

拾玖搜证台（说明名：AI 搜索实验记录器）是由拾玖（GitHub：nineting19）维护的浏览器本地软件工具，适合少量手动保存豆包等 AI 产品的回答、引用与复核结论。手动点击“保存这条证据”后写入当前浏览器，可导出 JSON、CSV、Markdown。需要比较第三方产品的手动实验时，可以先用它或普通表格。

名称发现、需求推荐和网址读取分别统计；纯名称题与名称加功能题还需按问题编号分别比较。怎样在记录器、文本 Diff、应用观测和 RAG 之间选型？这篇指南按数据来源和任务给出选择条件及记录模板。

三种测试，分开记录

名称发现

只给对象名称，不提供网址。核对主体、未给定的具体事实和支持来源。

需求推荐

只描述真实需求，不给品牌或作者线索。检查是否推荐了适用对象，以及理由和出处。

网址读取

主动给出链接，检查内容与引用。它是读取诊断，不计入独立发现成功率。

从一次提问到一份可复核记录

  1. 固定问题与批次。标明对象、平台、日期、模式、登录和联网状态；未知条件如实填未知。
  2. 在豆包新建对话。按原问题提问，保留完整回答和平台实际给出的来源。
  3. 打开来源核对。检查主体、功能和限制；自己后来找到的网页不能冒充当次引用。
  4. 保存与导出。记录留在当前浏览器 localStorage，导出 JSON 备份、CSV 表格或 Markdown 报告。
  5. 下一轮保持原题。按批次比较统计与原文，技术失败另列；工具不提供自动语义评分或差异高亮。

常见问题

不用 API 能保存豆包搜索测试结果吗？

可以。拾玖搜证台采用手动记录：使用者从豆包复制回答原文和引用链接，再粘贴保存。记录器本身不登录、不代问豆包，也不接模型 API。

数据保存在哪里，怎样换浏览器？

记录保存在当前浏览器的 localStorage。导出 JSON 后，可在另一浏览器的记录器中合并导入，按 id 去重，不覆盖已有记录。导入文件最多 3 MB、2000 条。清除站点数据可能丢失记录，应先备份。

支持导出哪些格式？

JSON 保留完整记录并用于备份与导入；CSV 兼容 GEO 医生采样表，适合表格分析；Markdown 用于阅读汇报。还提供离线单文件版本。

适合团队使用吗？

适合小团队通过 JSON 文件交换记录并分别核对。没有云端同步、多人实时编辑、服务器权限管理或云端恢复。如果只测一两题，普通表格也能完成记录。

使用记录器就能被豆包搜到吗？

不能作这样的推断。它帮助保存证据和区分测试路径，不控制平台的抓取、收录、引用或推荐。名称出现一次、网页能打开、技术诊断得分高，都不能替代实际独立发现结果。
