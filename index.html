分清你在验证什么

三种路径，分别核对。

读到了网页、按名字找到了、按需求推荐了，是三件不同的事。

01

名称发现

给出对象名称，让系统自行寻找来源。核对主体、具体事实和支持链接。

纯名称与“名称＋功能”还需按问题编号分开比较。

02

需求推荐

只描述需求，不给品牌、作者或网址。检查是否实际推荐了适用的对象。

它更接近真实用户还不知道产品名称时的提问。

03

网址读取

主动提供网址，检查页面能否读取、信息是否正确、引用是否支持结论。

这是读取诊断，单独统计。

使用方式

提问 → 核对 → 保存 → 备份

  1. 固定问题

    确定问题编号和批次，记录平台、日期、模式、登录与联网条件。

  2. 保留原始证据

    在平台正常提问，复制完整回答与当次来源；打开链接核对支持内容。

  3. 点击保存

    填写路径和复核标记，点击“保存这条证据”。记录留在当前浏览器。

  4. 导出再比较

    导出 JSON 备份、CSV 表格或 Markdown 报告。下一轮保持原题再测。

清除站点数据可能丢失记录。换浏览器或设备前请导出 JSON；没有自动同步，也没有未保存草稿的恢复承诺。
