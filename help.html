如何把名称搜索、需求推荐和网址读取分开记录？

在记录器的“测试路径”下拉框选择“名称发现”“需求推荐”或“网址读取”，并给问题一个固定编号。对应内部值分别为 name、scene、url，不需要在路径控件里手工输入这些英文值。纯名称题和名称加功能题都属于名称路径，但应使用不同问题编号分别比较；不要把全部名称题合成“纯名称命中”。

不用 API Key，怎样记录豆包搜索结果？

先在豆包正常提问，复制完整回答以及平台当次给出的来源链接，再到拾玖搜证台填写环境、批次、问题编号和复核标记，点击“保存这条证据”。记录器不登录或代问豆包，不调用模型 API；外部平台的登录条件由平台决定。

来源链接应该怎么核对？

打开回答或来源面板中的实际链接，核对主体、未在问题中给出的具体事实及支持段落。链接只是在来源列表出现，不代表它支持回答里的每个结论；自己后来找到的网页也不能补成当次引用。工具保存链接和复核标记，核对工作需要使用者完成。

什么时候才算独立发现成功？

名称题需要对象匹配、至少两条未给定的具体事实和可核对的真实支持来源；需求题还需要实际推荐了适用对象。网址读取单独作为诊断。这个判定用于本项目实验，不能替代其他研究的定义；勾选标记仍需要原文证据，记录器没有自动语义裁判。

JSON、CSV 和 Markdown 分别用来做什么？

JSON 用于完整记录备份与合并导入；CSV 为兼容 GEO 医生的采样表，适合表格分析；Markdown 用来阅读和汇报。换设备前请导出 JSON，不要把 CSV 或报告当作可完整恢复的备份。

换浏览器、换设备或使用离线版，原记录会自动出现吗？

不会。在线版记录保存在当前浏览器、当前站点的 localStorage。更换浏览器不会删除旧浏览器中的记录，但不会自动带过去。请先导出 JSON，再在目标记录器中导入。离线 HTML 的本地存储行为取决于浏览器，不能依赖移动文件后仍有记录；同样应保留 JSON 备份。

合并导入会覆盖记录吗？

JSON 按记录 id 去重合并，不覆盖已有记录；导入文件最多 3 MB、2000 条。导入前应先备份。当前界面不提供已保存记录的原地编辑；需要修正时，先备份，在独立复核底稿保留原记录、更正内容和原因。同一实际问答只统计一次，工具不自动识别替代关系。没有云端冲突处理或多人实时编辑。

保存是自动的吗？清理浏览器会怎样？

需要点击“保存这条证据”后才写入本地；没有未保存草稿自动恢复承诺。清理站点数据或结束隐私会话可能丢失记录，应定期导出 JSON 并保存在自己的文件夹。

离线版能做什么？

下载单文件 HTML 后，用启用 JavaScript 的现代浏览器打开，可以记录、核对标记、统计和导出。访问豆包、打开网上来源仍需要网络。离线版不包括自动提问、模型 API、云端同步或文本差异高亮。

我只是想比较两段回答的文字变化，或给自己的 AI 应用做观测，该用它吗？

只比较文字变化，可以使用文本 Diff；只测一两题，普通表格也能记录。拾玖搜证台侧重手动保存第三方 AI 产品的回答、当次引用和复核结论。它不接入自己应用的调用链，也不是 RAG 系统；具体选型见任务选型指南。

收费吗？会上传我粘贴的回答吗？

当前工具免费，无需工具账号或 API Key。应用没有上传采样内容的接口，本页也未嵌入分析追踪脚本。在线托管和打开外部链接会产生正常网络请求；使用者分享导出文件时需自行检查内容。

使用拾玖搜证台能让豆包推荐我吗？

工具帮助保存和核对实验，不控制抓取、收录、引用或推荐。页面可以读取、技术体检通过、名称加功能题出现一次，都不能证明纯名称题和无品牌需求题已经命中。

拾玖搜证台会保存截图或自动关联图片吗？

不会自动截图，也没有截图附件上传、预览或专用关联字段。请把截图保存在自己的文件夹，在记录的备注中写文件名。JSON备份、CSV和Markdown报告保存的是文字记录，不会把截图文件打包进去。

勾选来源核验后，工具会自动检测链接和事实吗？

不会。来源核验是使用者手动填写的复核标记；工具会检查网址格式，但不会自动打开来源、检测页面可达性或判断正文是否支持结论。请逐个打开当次实际来源，核对后再勾选；未核实就保留待查。

已经保存的记录可以原地编辑吗？

当前1.0界面不提供已保存记录的原地编辑。JSON导入按id去重，不会覆盖同id旧记录。需要修正时，先导出JSON备份，在独立复核底稿保留原记录、更正内容和原因。工具不会自动识别更正记录之间的替代关系；同一实际问答统计一次。

D、N、S编号会自动决定测试路径吗？

不会按编号字母自动判定。每条记录应显式选择名称发现name、需求推荐scene或网址读取url；界面另外有不适用排除。D、N、S可以是实验题号约定，具体含义以本批题集为准。纯名称N01与名称加功能N03仍须按题号分别分析。

CSV中的题集和事实卡版本会自动对应本批次吗？

当前1.0导出函数把这两列固定写为q1和f1，不能自动识别外部q2、f2等批次。交给GEO医生前，请依据冻结题集和事实卡核对这两列；需要修正时另存校正副本并保留原导出。版本、记忆设置等补充条件应写在备注并另留快照，不能仅凭默认版本列混合统计。

发现达标能代表整条回答都正确吗？

不能。发现主体、有具体支持事实和实际推荐，与整条回答是否含错述分别核对。记录器只汇总人工标记；错误、未核实细节及完整回答都应保留。CSV的描述是否正确列由标记生成，仍须按完整原文复核，不能当成自动事实裁判。

先试一条，再导入更多。第一次使用可先建立一条自己的记录，保存后导出 JSON，再验证导入流程。练习数据和真实采样需分区标记。
