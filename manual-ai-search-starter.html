免费免注册，具体指哪些部分？

记录器无需账号、API Key 或付费订阅。现代浏览器需要启用 JavaScript。你仍要自行满足豆包等被测平台的正常登录和访问条件；记录器不会处理登录、验证码或访问限制。

记录留在当前浏览器的 localStorage，应用没有上传采样内容的接口。打开在线站点、下载文件和查看外部引用仍会产生网络请求。需要离线整理时，可以下载单文件 HTML 记录器；它用于整理已有回答，不能离线调用豆包。

一条测试怎样保存？

  1. 先确定问句、问题编号、批次和判定标准。在目标产品里正常开新对话提问，不在同一对话里补充目标网址或答案线索。
  2. 在记录器选名称发现、需求推荐或网址读取。纯名称和名称加功能题保留不同题号，不能合并成“只给名字已成功”。
  3. 保存问句和完整回答，填写当次入口、可见模式、登录、联网及地区。无法核实的写未知，不把 API 回答当作网页端结果。
  4. 复制回答当时实际提供的引用。打开来源，核对它是否支持正确主体和具体事实；自己后来找到的链接应另作调查资料，不能冒充当次引用。
  5. 选择回答状态，记录人工复核结论，然后点击“保存这条证据”。尚未提交的输入没有自动保存承诺。

拒答、报错、完整未命中怎样区分？

你在界面实际看到的情况记录状态或判定是否进入有效回答分母
正常回答，并正确识别、提供足够事实与支持来源；需求题还确实推荐适用工具完整回答；人工核对达标是，符合严格标准时计成功
完整回答“没有找到”，或只推荐其他对象完整回答；未达标是，不计成功
模型明确拒绝提供回答拒答是，不因拒答自动计成功
网络异常、登录或平台验证阻断，尚未得到完整回答技术失败；保留具体原因否，单列报告
生成未结束、原文截断或完成状态无法确认不完整否，单列报告

“完整未命中”是依据可见回答作出的人工发现判定，不等于你知道平台内部检索返回了零条文档。只有消费者网页回答时，看不到检索 span、内部索引和完整召回集合，不能臆造这些字段。技术失败后也不应反复追问到满意；重新测试要另记批次或轮次，保留原故障。

不符合原题条件、给了品牌或网址线索的需求题，以及模拟练习，都应单独标记，不混进正式需求推荐成绩。

JSON、CSV、Markdown 分别怎样用？

文件用途边界
JSON完整备份和重新导入，保留原文按 id 合并去重、不覆盖已有记录；导入上限 3 MB、2000 条
CSV表格整理及 GEO 医生采样表不是记录器 JSON 导入格式；自定义研究的版本信息须按实际批次核对
Markdown通读、汇报和人工复核可读报告，不是可重新导入的完整备份

导出只作用于当前筛选范围。备份全部真实记录时，先返回真实采样区并选择全部，再点击“导出 JSON”。选择“导出 CSV”和“导出报告”分别生成表格和 Markdown。

空白模板用于起步，里面没有模型回答、成功样本或虚构客户数据。JSON 模板没有记录；导入空文件不会替你生成实验。三种格式最可靠的工作流，是先在记录器保存真实证据，再从同一筛选范围导出。

怎样移交给另一台电脑？

保留 JSON 备份，在目标浏览器的对应区域点“导入 JSON”，核对待合并提示并点“确认合并”，再检查条数与选定原文，刷新后确认记录仍在。相同 id 不覆盖，条数不一定直接相加。清理站点数据可能丢失本地记录；换浏览器本身不会删除旧浏览器的那份数据。

文件交换不等于实时协作。本工具没有服务器恢复、统一权限或自动跨设备同步。需要这些能力时，应选择相应的协作或观测系统；只想自动抓取聊天页面时，应另行评估合适的导出工具和平台规则。
