## 根目录文件

- robots.txt 在域名根目录明确允许抓取并指向站点地图。根域名此前返回 404；404 本身不代表禁止抓取，不能声称此改动修复了豆包未命中的原因。
- sitemap.xml 为站点地图索引，链接根页及已有项目站点地图；原有项目 URL 保留。
- llms.txt 仅供导航，不是收录或排名保证。
- 页面为直接含正文的静态 HTML，不依赖 JavaScript 显示产品说明。
